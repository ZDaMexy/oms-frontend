第一次使用 OMS

  1. 从下载页进入公开发行，下载完整客户端 ZIP 并完整解压。
  2. 在 Windows 上启动客户端，核对数据目录和输入设置。
  3. 选择 BMS 或 mania，添加自己的谱面后开始游玩。离线游玩不需要社区账号。

公开下载的是 20260626 版，尚不支持 IR。使用说明请以所下载版本为准。

添加自己的谱库

OMS 支持 BMS 和 mania。在客户端添加谱库文件夹并扫描谱面；请保留配套音频、图片和其他原始文件。

BMS 采用原谱目录，mania 使用自己的原谱目录。发帖或使用 IR 都不需要上传谱包。若有扫描问题，发帖时说明版本、玩法、操作步骤和可复现现象。

开启 IR 与查询成绩

使用支持 IR 的开发版，从工具栏的账号入口打开连接设置。填写 https://oms.zdamexy.work，勾选“启用 IR”并保存，然后登录。IR 默认关闭，离线游玩无需账号。

社区和 IR 使用同一账号。游戏结算先保存本地成绩，再尝试交分；网页可以查看同条件谱面榜和本人记录。断网后仍可保留待交成绩，重新连接并使用原账号补交。匿名游玩不会自动归入后来登录的账号。

打开 IR → 当前榜单是客户端自报的试验榜，未经回放核验。自动游玩只保留在本人记录，不能作为公开排名。

按来源查看 BMS 榜单

在IR输入原谱 MD5，或搜索标题、作者，再选择一个、多个或全部来源。参考混榜按原 EX 排序；来源选择同时改变最佳分、独立灯、人数、名次和分页。同分共享名次；同一 OMS 账号的新来源成绩合并显示，历史旧账号始终保留独立 ID。

“同条件榜”需要主动选择已确认条件，目前仅包括 OMS 相同内容、规则和最大 EX。外部播放器和历史摘要中尚未证明的判定、血条或长条条件不会自动加入；可随时回到参考混榜。每种原灯独立展示，不换算成跨播放器最高灯。OMS 游戏内可从当前 BMS 原谱直接打开同一榜；所用开发版本需具备此入口，公开的 20260626 版尚无此入口。

LR2IR 基础榜来自公开 v3 归档与展示工具（2026-05-31 快照），保留谱面 MD5、旧玩家 ID、行内名称、原 EX、物量和原通关灯。没有可信逐局时间或账号认领；名称相同不表示是你的 OMS 账号。来源未收录时显示“未知客户端”，原始字段缺失如实显示。归档作者的异常标记与数值矛盾记录不进入排名，不能用它们处罚当前账号。个人资料、留言、次数和 ghost 不在此榜导出范围；需要处理历史行的公开可见性时，通过联系入口核实旧 ID 与谱面 MD5。

连接播放器

  1. 登录 IR 页，在“播放器专用密钥”中选择对应来源并创建密钥。密钥只显示一次，请及时保存；泄露或停用时撤销。不要填入网页密码。
  2. Java 插件放入播放器的 ir/ 目录，确保启动器加载该目录。在配置页选择对应 OMS IR 并启用，ID 填 OMS，密码栏填该来源专用密钥，再重启。密钥可能以可恢复形式保存在播放器目录中，请保护该目录及备份。
  3. OpenLR2 按宿主架构选择 DLL，与 omsir.json 一起放入 LR2files/CustomIRs/OmsIR/。JSON 填写 origin（https://oms.zdamexy.work）和 integration_key（OpenLR2 专用密钥），启用 OMS IR (OpenLR2 v260915) 后重启。
  4. 完成一局正常游玩，查看交分提示，并核对播放器和网页上同 MD5 的榜单。插件上传接入后的最佳状态更新，不会批量导入旧存档，也不提供逐局历史。
支持范围与原生榜显示限制

自动、练习、回放、特殊修改、已知辅助、随机分支及 CN / HCN 不在当前已确认接入范围。成绩由播放器上报，未经回放核验。

OpenLR2 只报告有无长条，类型可能未知。未提供 BP 时，原生皮肤可能显示 0，不能据此当作零 BP。原生榜并列行显示列表位置；网页与 OMS 显示共享名次。

原生整榜超过人数或字节上限时会明确失败，可以改用网页查榜，交分仍可使用。关闭 IR 不影响离线游玩；网络失败不会阻止本地保存。

社区约定

可以讨论玩法、求助、分享谱面入口和记录开发变化。发帖选择合适分类，标题写清主题；求助尽量附上版本、步骤和现象。

正文目前支持纯文本与安全的网页链接。请不要发布密码、账号令牌、个人联系方式或含私密信息的日志；也不要冒用他人身份、刷屏或发布无授权资源。维护者可以隐藏违规内容，申诉可通过下方项目联系入口。

帖子和回复对所有访客公开。你可以编辑或删除自己的内容；删除帖子会保留他人的回复与删除占位，并关闭后续回复。

数据与隐私

注册账号会保存账号名和密码摘要，密码不会以原文保存。帖子、回复、作者名与发布时间公开；IR 本人历史只向当前账号开放，公开榜单会显示账号名。

你可以删除自己发布的帖子或回复，正文将不再公开显示，作者、时间与删除占位仍保留，其他人的回复也会保留。IR 成绩与账号数据删除需联系维护者并核实归属；已有维护备份按留存期限到期。网站不上传客户端谱面或回放。

登录使用浏览器 cookie，不在 localStorage 保存账号令牌。发帖失败时，本页会保留尚未提交的文字供重试；离开页面会有提示，不把草稿存入浏览器长期存储。

目前没有邮箱绑定、自动找回密码或网页自助销号。忘记密码、申请删除账号数据或需要处理违规帖，请通过项目联系入口与维护者核实。只知道账号名不足以证明账号归属。

联系与反馈

一般问题请到社区发求助帖，便于其他玩家参与讨论。可复现的客户端问题也可以提交到GitHub Issues。

需要账号恢复、数据删除或私下处理违规内容时，请在 QQ 搜索群号 650530995，联系群内维护者。不要在公开帖子里贴密码或账号凭据。
