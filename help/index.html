GETTING STARTED

从第一局，到第一篇帖子。

入门、IR 和社区的基本说明放在这里。找不到答案时，可以直接发帖求助。

第一次使用 OMS

  1. 从下载页进入公开发行，下载完整客户端 ZIP 并完整解压。
  2. 在 Windows 上启动客户端，核对数据目录和输入设置。
  3. 选择 BMS 或 mania，添加自己的谱面后开始游玩。离线游玩不需要社区账号。

当前开发版本与公开发行包可能不同；请阅读所下载版本的说明。OMS 网站不会自动替你升级客户端。

添加自己的谱库

OMS 只保留 mania 与第一类 BMS。你可以在客户端注册自己的外部谱库目录，并扫描其中的谱面；请保留谱面所需的音频、图片和其他原始文件。

BMS 采用原谱目录，mania 使用自己的原谱目录。不要为了发帖或使用 IR 上传整份谱包。若有扫描问题，发帖时说明版本、玩法、操作步骤和可复现现象。

开启 IR 与查询成绩

IR 默认关闭，离线游玩照常可用。仅当所用客户端版本具备本轮 IR 接入时，主动填写服务地址 https://oms.zdamexy.work、启用 IR，再登录账号。

社区和 IR 使用同一账号。游戏结算先保存本地成绩，再尝试交分；网页可以查看同条件谱面榜和本人记录。断网后仍可保留待交成绩，重新连接并使用原账号补交。匿名游玩不会自动归入后来登录的账号。

打开 IR → 当前榜单是客户端自报的试验榜，未经回放核验。自动游玩只保留在本人记录，不能作为公开排名。

按来源查看 BMS 榜单

在IR输入原谱 MD5，或搜索标题、作者，再选择一个、多个或全部来源。参考混榜按原 EX 排序；来源选择同时改变最佳分、独立灯、人数、名次和分页。同分共享名次；同一 OMS 账号的新来源成绩合并显示，历史旧账号始终保留独立 ID。

“同条件榜”需要主动选择已确认条件，目前仅包括 OMS 相同内容、规则和最大 EX。外部播放器和历史摘要中尚未证明的判定、血条或长条条件不会自动加入；可随时回到参考混榜。每种原灯独立展示，不换算成跨播放器最高灯。OMS 游戏内可从当前 BMS 原谱直接打开同一榜；所用开发版本需具备此入口，旧公开发行包不因此升级。

LR2IR 基础榜来自公开 v3 归档与展示工具（2026-05-31 快照），保留谱面 MD5、旧玩家 ID、行内名称、原 EX、物量和原通关灯。没有可信逐局时间或账号认领；名称相同不表示是你的 OMS 账号。来源未收录时显示“未知客户端”，原始字段缺失如实显示。归档作者的异常标记与数值矛盾记录不进入排名，不能用它们处罚当前账号。个人资料、留言、次数和 ghost 不在此榜导出范围；需要处理历史行的公开可见性时，通过联系入口核实旧 ID 与谱面 MD5。

其他播放器接入试运行

当前固定目标为 beatoraja 0.8.8、LR2oraja build11611350155、Endless Dream v0.4.0 和 OpenLR2 v260915；真实宿主、架构及 5K / 7K / 14K 普通与标准长条仍需逐项真人验收。先导为 Endless Dream 7K，不能由一个版本通过推断其他版本或玩法完成。

Java 候选插件：Endless Dream v0.4.0、beatoraja 0.8.8、LR2oraja build11611350155。已通过编译和固定发行 SDK 的实际交分、原生整榜回读，验证使用合成宿主数据，不能代替真实游玩。

OpenLR2 v260915 候选插件：x64 DLL、x86 DLL；按宿主架构选择，不能混用。两份 DLL 已通过固定工具链编译和软件入口加载，真实宿主仍待验收。插件使用 nlohmann/json，附MIT 许可证通知。所有插件仅对应这些固定发行文件；版本与文件校验记录保留实际来源与验证范围。

  1. 登录 IR 页，在“播放器专用密钥”中选择对应来源并创建密钥。秘密只显示一次，妥善保管；泄露或不再使用时撤销。不要填入网页密码。
  2. Java 插件放入现有播放器的 ir/ 目录，确保启动器加载该目录，在配置页选择对应 OMS IR 并主动启用；ID 可填 OMS，密码栏填该来源专用密钥，重启播放器。播放器配置中的可逆加密不等于系统凭据库，请保护播放器目录和备份。
  3. OpenLR2 将匹配架构 DLL 与 omsir.json 放入现有宿主的 LR2files/CustomIRs/OmsIR/。JSON 仅填写 origin（服务地址 https://oms.zdamexy.work）和 integration_key（OpenLR2 来源专用密钥）；在宿主配置中主动启用 OMS IR (OpenLR2 v260915)，再重启播放器。
  4. 用正常单谱完成一局，查看宿主交分提示，再打开本来源原生榜及网页同 MD5 榜核对。只有新回调的最佳状态被观察，旧存档不会自动批量上传；重复或较差成绩不增加虚假的局数。

自动、练习、回放、特殊修改、已知辅助、谱面随机分支及 CN / HCN 不在当前已确认接入范围；宿主允许提交仍不代表服务核验成绩。OpenLR2 只报告有无长条，长条类型仍可能未知；未提供 BP 时原生皮肤仍可能画成 0，这不是真实零 BP。原生榜并列行显示列表位置，不代表共享名次；网页与 OMS 保留共享排名及未知字段说明。原生整榜超过人数或字节预算时明确失败，可继续网页查榜，交分仍可用。关闭 IR 后离线游玩照常；网络失败不能阻塞本地保存。

社区约定

可以讨论玩法、求助、分享谱面入口和记录开发变化。发帖选择合适分类，标题写清主题；求助尽量附上版本、步骤和现象。

正文目前支持纯文本与安全的网页链接。请不要发布密码、账号令牌、个人联系方式或含私密信息的日志；也不要冒用他人身份、刷屏或发布无授权资源。维护者可以隐藏违规内容，申诉可通过下方项目联系入口。

帖子和回复对所有访客公开。你可以编辑或删除自己的内容；删除帖子会保留他人的回复与删除占位，并关闭后续回复。

数据与隐私

注册账号会保存账号名和密码摘要，密码不会以原文保存。帖子、回复、作者名与发布时间公开；IR 本人历史只向当前账号开放，公开榜单会显示账号名。

你可以删除自己发布的帖子或回复，正文将不再公开显示，作者、时间与删除占位仍保留，其他人的回复也会保留。IR 成绩与账号数据删除需联系维护者并核实归属；已有维护备份按留存期限到期。网站不上传客户端谱面或回放。

登录使用浏览器 cookie，不在 localStorage 保存账号令牌。发帖失败时，本页会保留尚未提交的文字供重试；离开页面会有提示，不把草稿存入浏览器长期存储。

目前没有邮箱绑定、自动找回密码或网页自助销号。忘记密码、申请删除账号数据或需要处理违规帖，请通过项目联系入口与维护者核实。只知道账号名不足以证明账号归属。
