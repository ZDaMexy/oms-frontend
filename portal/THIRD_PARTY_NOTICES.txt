Changes include actual catalog/search/detail/scoreboard/profile/ranking,
home/news, navigation, pagination, forum and download composition adapted to
OMS data and on-demand APIs. The existing native-CSS portal subset remains
in use; selected Less sources also compile into player-site.css. ppy global
controllers, routes, unavailable statistics and asset dependencies are
removed or replaced by explicit OMS data, system fonts and the existing
OMS logo. News contains maintained OMS publications, not fabricated player
activity. No ppy/osu! branding, upstream artwork, font files or icon files
are included. Source-provided covers are external images, not bundled ppy
assets. The full osu!web server stack and accounts are not included.

Corresponding source for a released version:
  /portal/oms-website-source.tar.gz
The archive contains the exact release's unminified TypeScript/TSX/Less,
OMS integration sources, runtime HTML/JavaScript/CSS, notices, package.json,
package-lock.json, tsconfig.json, webpack.config.cjs and build instructions
at web/src/BUILD.md. The fixed mapping is at web/src/osu-web/upstream.json;
all current local-source hashes and exact website/backend commits are bound
by source-manifest.json. A compressed/minified JavaScript bundle alone is
not the source offer. Build the extracted web directory using Node 22 and
the fixed npm lock as described in web/src/BUILD.md; production uses static
assets and the separate same-origin service, without a Node server.

Corresponding service runtime/installation source is also included in the
archive under backend/. No node_modules, developer caches, player records,
databases, raw personal data, SDK/adapter binaries or deployment credentials
are included. The independent service and player adapters are not osu!web
implementations; their source and dependency licenses remain separate.
