`other/` 用于记录尚未进入主线或支线的调研、运维事项、杂项问题与外部信息。

## 常见内容

- 官网参考案例与竞品调研
- 域名、TLS、Nginx、缓存策略等运维事项
- 素材来源、文案来源、社区反馈与开放问题

## 使用原则

- `other/` 里的内容不直接覆盖主线结论
- 一旦某条调研结论影响计划、状态、约束或验证结论，必须同步提升到对应主线文档
