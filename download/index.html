下载 OMS

OMS 是 Windows-only、离线优先的 BMS 与 mania 客户端。

Windows 公开发行

oms_20260626

下载完整 ZIP，解压后启动。公开版本与开发源码分别更新，请以发行说明为准。

打开 GitHub 发行页 ↗ 历史版本

适用系统：Windows。请使用发行页提供的完整客户端 ZIP，GitHub 自动生成的 Source code 是源码。

公开发行包 oms_20260626 尚未包含 IR 接入。网页可查看试运行榜单；客户端交分需要支持 IR 的开发版本。
1

下载并解压

完整解压到一个自己管理的目录，再运行 OMS。更新前阅读对应版本的说明，并备份自己的数据；不要把新包解压到正在运行的程序目录。

2

添加谱面，设置输入

在客户端设置中添加自己的谱库，选择 BMS 或 mania，并核对键位。查看谱库入门 →

3

离线游玩与按需交分

离线游玩不要求注册社区账号。遇到问题或有心得，可以来社区发帖；使用支持 IR 的开发版本时，再主动开启交分。
